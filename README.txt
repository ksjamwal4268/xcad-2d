Welcome to XCAD 2D!
A lightweight, high-performance 2D CAD drafting suite built for architectural,
civil, electrical, and mechanical drafting practice.

Designed to be ultra user-friendly so that ANYONE—students, friends, beginners,
or experienced AutoCAD drafters—can start drawing immediately without confusion!

--------------------------------------------------------------------------------
HOW TO RUN:
--------------------------------------------------------------------------------
1. Simply double-click "XCAD 2D.bat" (or "Launch XCAD 2D.bat").
2. The application opens immediately in a dedicated desktop CAD window
   (no browser address bar, tabs, or bookmarks).
3. Zero installation or plugins required. Runs 100% offline on any Windows PC!

--------------------------------------------------------------------------------
NEW USER-FRIENDLY FEATURES (EASY DRAFTING FOR ANYONE):
--------------------------------------------------------------------------------
1. 📂 READY-MADE SAMPLE TEMPLATES (Instant Practice):
   - Click "📂 Templates" in the top bar to load:
     * 🏠 2BHK Architectural Floor Plan (Living, Master Bed, Kitchen, Bath, Balcony)
     * 📐 Civil Survey & Site Boundary (Lot boundary, setback, road, benchmarks)
     * ⚙️ Mechanical Bearing Flange (Contour, PCD bolt circle, shaft keyway)
   - Great for testing and learning CAD concepts in 5 seconds!

2. 🖱️ INTERACTIVE COMMAND ACTION PILLS:
   - Don't know keyboard shortcuts? No problem! Clickable buttons appear inside
     the command bar at the bottom:
     * Drawing Polyline: Click [Close], [Finish (Enter)], or [Cancel (Esc)]
     * Drawing Line: Click [Finish (Enter)] or [Cancel]
     * Selected Objects: Click [Move], [Copy], [Delete], or [Deselect]

3. 🔍 FLOATING QUICK PROPERTIES INSPECTOR:
   - Click on any object to open the Quick Properties card in the bottom-right.
   - Shows length, radius, bounding size, layer selector, and 1-click color palette.

4. 🚪 1-CLICK ARCHITECTURAL SMART BLOCKS:
   - On the Home Ribbon, simply click "Door", "Window", "Desk", "Column", or "Toilet"
     to immediately drop them into your plan with intelligent snapping.

5. 🖐️ AUTO-DRAG (DIRECT MOVE):
   - Click on any object or group of selected objects and drag them directly
     with your mouse. No need to type 'M' or 'MOVE'!

--------------------------------------------------------------------------------
KEYBOARD SHORTCUTS & COMMANDS CHEAT SHEET:
--------------------------------------------------------------------------------
--- Draw Tools ---
L           : Line (continuous straight segments)
PL / PLINE  : Polyline (multi-segment connected lines, type 'C' to close)
C           : Circle (center point + radius)
A           : 3-Point Arc
REC         : Rectangle
H           : Hatch (Boundary-free and path hatching: ANSI31, ANSI37, SOLID, BRICK)

--- Modify & Edit ---
AUTO-DRAG   : Click and drag any selected object directly to move it!
M           : Move selected objects
CO / CP     : Copy selected objects
RO          : Rotate selected objects around base point (e.g. RO -> 45)
SC          : Scale selected objects around base point (e.g. SC -> 2)
MI          : Mirror selected objects across 2-point axis
F           : Fillet corners (meet at corner) or tangent arc with radius
X           : Explode Smart Block, Polyline, or Rectangle into lines
J           : Join touching lines into a continuous Polyline
TR          : Quick Mode Trim (click line to trim; hold Shift to Extend!)
EX          : Quick Mode Extend (click line to extend; hold Shift to Trim!)
O           : Offset parallel
E / DEL     : Erase selected objects
AR          : Dynamic Rectangular Array (rows, columns, spacing)
ARRAYPOLAR  : Dynamic Polar Array (circular distribution around center point)
LA / LAYER  : Open Layer Properties Manager dialog
RE / REGEN  : Regenerate model and refresh display

--- Coordinate & Precision Drafting (AutoCAD Power Drafter) ---
SPACEBAR    : Acts as ENTER everywhere! Press Spacebar on canvas to finish lines or repeat last command!
Direct Dist : Click first point, point cursor in any direction, type distance (e.g. 150) and hit Space!
Polar Coords: Enter 'dist<angle' (e.g. 100<45) for exact polar vectors
Relative    : Enter '@dx,dy' (e.g. @100,0 or @0,-50) from previous point
Absolute    : Enter 'x,y' (e.g. 100,200) for exact world coordinates
Rectangle   : Type 'w,h' or '120x80' while creating rectangle for exact dimensions
Circle      : Type radius (e.g. 50) or 'D 100' for diameter input
Fillet      : Type 'R' to set fillet radius (e.g. R 10), then select 2 lines

--- Precision Snapping & Measuring ---
F1 / ?      : Open Help & Shortcuts Guide
F3          : Toggle OSNAP (Endpoint, Midpoint, Center, Centroid)
F8          : Toggle ORTHO (locks movement strictly to 90° horizontal/vertical)
F10         : Toggle Polar Tracking (15°, 30°, 45°, 90° reference rays)
F12         : Toggle Dynamic Input Heads-Up Display
QM          : Quick Measure Neon Proximity HUD (hover to see wall dimensions)
DI / DIST   : Measure exact distance, angle, and delta X/Y

--- Annotations & Schedules ---
DIM         : Smart Dimensioning (automatic linear, aligned, and radius detection)
ML / MLEADER: Associative Multi-Leader annotations with arrowheads and text notes
T / MTEXT   : Text annotation
CM          : Center Mark on circles and arcs
CL          : Associative Centerline between lines
COUNTTABLE  : Insert live block count schedule table into model space
DATAEXTRACTION : Export schedule & quantities to CSV / Excel

--- AI Smart Blocks Ecosystem ---
BCONVERT    : Autodesk AI Search & Convert (scans drawing for matching linework)
BLOCKREPLACE: Batch replace blocks while preserving attributes & alignment
COUNT       : Open Intelligent Block Count Palette
I / INSERT  : Insert architectural blocks (Doors, Windows, Desks, Columns, Toilets)

--- GIS & Site Planning ---
GEO         : Assign real-world GPS Latitude/Longitude (WGS84)
GIS / BASEMAP: Stream live Satellite, OpenStreetMap, Streets, or Dark Canvas maps
MAPCAPTURE  : Capture aerial imagery as static CAD raster underlay

--- Collaboration, Review & Automation ---
TRACE       : Collaborative transparent markup review overlay
COMPARE     : DWG Compare visual diff engine (highlights additions/deletions)
INSIGHTS    : Activity Insights version revision timeline
LISP / VLISP: AutoLISP IDE console and S-expression script automation
CTRL+0 / F11: CleanScreen (full-screen distraction-free drafting)
U / CTRL+Z  : Undo
REDO / CTRL+Y : Redo
DXF         : Export official AutoCAD-compatible ASCII DXF file
SAVE        : Save project file (.cad)
CLEAR / NEW : New drawing canvas

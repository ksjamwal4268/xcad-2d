❓ XCAD 2D - Quick Start & AutoCAD Shortcuts Guide
🖱️ Mouse & Trackpad Gestures (Super Easy)
Left ClickClick on empty canvas to start selection, or click an entity to select it.
Auto-DragClick on any selected object and drag your mouse to move it across the canvas!
Right ClickFinishes the active command (Enter) or repeats the last command!
Scroll WheelZoom in / zoom out anchored to your cursor position.
Middle-Click DragPan your viewport across the infinite CAD world.

CCircle (center + radius)

🛠️ Modify & AutoCAD Shortcuts
M / COMove / Copy selected objects
RO / SCRotate / Scale around base point

TR / EXQuick Trim / Extend (Shift flips)

⌨️ Function Keys & Fullscreen
F3Toggle OSNAP (Endpoint, Midpoint, Center, Centroid)
F8Toggle ORTHO mode (locks cursor strictly to horizontal & vertical)
F10Toggle Polar Tracking (15°, 30°, 45° alignment rays)
F12Toggle Dynamic Input (heads-up coordinate display near crosshair)
F11 or CTRL+0CleanScreen Fullscreen Mode
U / CTRL+ZUndo last action
REDO / CTRL+YRedo action
